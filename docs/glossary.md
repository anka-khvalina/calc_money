# Глоссарий

Краткий словарь терминов FairOddsCalc.

## Исходы 1X2

| Символ | Значение |
|--------|----------|
| **P1** / **1** | победа хозяев |
| **X** | ничья |
| **P2** / **2** | победа гостей |

## Коэффициенты

- **Closing odds** — закрывающие коэффициенты перед матчем (источник обучения).
- **Честный коэффициент** — `k = 1 / p` после снятия маржи.
- **De-vig** — приведение имплицитных вероятностей к сумме 1 (метод **Shin** в коде).

## Голевая модель

| Параметр | Смысл |
|----------|--------|
| **S** / **S_m** | ожидаемая сумма голов `λ_h + λ_a` |
| **D** / **D_m** | разница голов `λ_h − λ_a` |
| **λ_h**, **λ_a** | интенсивности голов хозяев и гостей |
| **H** | домашнее преимущество (рейтинг силы) |
| **H_g** | домашний бонус в log-головах |
| **μ, A, Df** | база и attack/defense в log-модели |

## Веса матча

| Поле БД | Смысл |
|---------|--------|
| `match_weight` | ручной множитель качества матча (бывш. CSV `value`) |
| `derby_weight` | множитель дерби |
| `neutral_weight` | множитель нейтрального поля |
| `season_weight` | вес сезона на вкладке «Линия» |

```text
w = season_weight × match_weight × derby_weight × neutral_weight
```

## Рынки

- **AH** — азиатская фора (`closing_ah_home`, коэффициенты AH1/AH2).
- **Тотал** — `closing_total_line`, Over/Under.
- **ИТ** — индивидуальный тотал команды.

## Supabase

- **`v_matches_full`** — view: матч + названия команд и лиги.
- **`v_season_summary`** — агрегат сезонов с `matches_count`.
- **`matches`** — таблица для PATCH кэфов и весов.
