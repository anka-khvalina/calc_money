# Обучение и расчёт линии — подробная справка

Полное описание голевой модели во вкладке **«Линия»** (web/iOS и desktop).  
Краткие формулы: [calculation.md](calculation.md). Маппинги БД: [reference.md](reference.md).

---

## 1. Идея

Из **closing-коэффициентов** прошлых матчей модель учится оценивать силу команд, атаку/оборону и домашнее преимущество.  
Для **нового матча** строится одна пуассоновская матрица счётов `P(i,j)` — из неё согласованно получаются 1X2, тоталы, форы, ИТ.

```text
История матчей (Supabase)
    → для каждого матча: Shin de-vig → скрытые S, D → λ_h, λ_a
    → обучение: рейтинг r, атака A, оборона Df, калибровка, ничья
Прогноз матча
    → λ_h, λ_a из рейтингов → матрица → коррекция ничьи → все рынки
```

## 2. Какие данные нужны

### Обязательно для обучения (каждый матч)

| Поле БД | UI | Смысл |
|---------|-----|--------|
| `home_team`, `away_team` | Хоз / Гост | имена как в справочнике |
| `closing_ah_home` | AH | линия форы **на хозяев** |
| `ah_home_odds`, `ah_away_odds` | AH1, AH2 | кэфы на покрытие форы |
| `closing_total_line` | Тот | линия тотала |
| `over_odds`, `under_odds` | O, U | кэфы тотала |

Матч **не попадает в обучение**, если нет полной линии (фора + тотал + все четыре кэфа).

### Желательно

| Поле | Зачем |
|------|--------|
| `home_odds`, `draw_odds`, `away_odds` | калибровка S/D под 1X2; модель ничьи |
| `is_neutral` | без домашнего преимущества в этом матче (`H_eff = 0`) |
| `match_weight` | качество матча (низкая мотивация → 0.5 и т.д.) |
| `derby_weight` | **флаг дерби**: `1` = да, `0` / `null` = нет; поправка к **H** при обучении |
| `neutral_weight` | ослабление веса при обучении, **только** если `is_neutral` |
| `note` | заметка (`low_motivation`) — **не влияет на формулу** |

### Вес сезона

На вкладке **«Линия»** — таблица весов по `season_id` (после загрузки из БД).  
Default: 1.0 для каждого выбранного сезона.

## 3. Азиатская фора — знак и смысл

**В БД хранится как у букмекера** (`closing_ah_home` — фора на хозяев):

| Линия | Кто сильнее | Пример |
|-------|-------------|--------|
| **−0.75, −1, …** | хозяева фаворит | Inter −1 @ AH1 2.83 / AH2 1.49 |
| **+0.25, +0.5, …** | хозяева аутсайдер | |

**Высокий AH1 при минусовой линии** — нормально: покрыть жёсткую фору сложнее, чем выиграть «в ноль» на 1X2.

**Программа не меняет знак линии** при основном расчёте:

```text
P_fair(AH home) = Shin de-vig(AH1, AH2)
D = подбор так, чтобы P(хозяева покрыли фору | S, D) = P_fair
```

Линия **−1** подставляется в формулу покрытия **как есть**.  
Внутренний параметр **D = λ_h − λ_a** (ожидаемая разница голов) обычно **положительный**, если хозяева сильнее — это не то же самое, что знак в БД.

Покрытие форы (счёт `i:j` у хозяев):

```text
margin = (i − j) + closing_ah_home
```

margin > 0 → хозяева покрыли (с учётом push на целых/четвертных линиях).

**Запасной путь** (нет AH-кэфов, только линия): `D ≈ −closing_ah_home`.

## 4. Обучение — по шагам

### Шаг 0. Загрузка

1. Лига + сезоны → **«Загрузить из БД»**.
2. Проверка: внизу число матчей «к обучению допущено».
3. При необходимости — веса сезонов → **«Обучить модель»**.

### Шаг 1. Shin de-vig (каждый матч)

Для каждого рынка отдельно снимается маржа методом **Shin**:

- тотал: Over / Under  
- фора: AH1 / AH2  
- 1X2: 1 / X / 2  

Получаем честные вероятности `P_fair`, сумма = 1.

### Шаг 2. Скрытые S и D матча

**S** — ожидаемая сумма голов `λ_h + λ_a`:

```text
S = argmin ( fair_price_model(Over | S) − P_fair(Over) )²
```

`fair_price_model(Over)` — **не** обычная вероятность `P(G > line)`, а честная модельная цена азиатского тотала:

| Линия | Формула q |
|-------|-----------|
| **2.5** | `q = P(G ≥ 3)` |
| **2.0** | `q = P(G ≥ 3) / [P(G ≥ 3) + P(G ≤ 1)]` (push на 2 голах) |
| **2.25** | `W = P(G≥3)`, `L = P(G≤1) + ½·P(G=2)`, `q = W/(W+L)` |

Общий вид: `W = Σ P(G=g)·(full_win + ½·half_win)`, `L = Σ …·(full_loss + ½·half_loss)`, `q = W/(W+L)`.

Сумма голов `G ~ Pois(S)`. По линии тотала и de-vig Over/Under (не просто «линия = ожидание»).

**D** — ожидаемая разница `λ_h − λ_a`:

```text
D = argmin ( fair_price_model(AH home | S, D) − P_fair(AH home) )²
```

`fair_price_model(AH home)` — не просто `P(margin > 0)`, а честная модельная цена с азиатским settlement:

```text
margin = (голы хозяев − голы гостей) + closing_ah_home

простая линия:  margin > 0 → win;  margin = 0 → push;  margin < 0 → loss
четвертная:     −0.25 = ½·AH(0) + ½·AH(−0.5);  +0.75 = ½·AH(+0.5) + ½·AH(+1.0)

W = Σ P(i,j)·(full_win + ½·half_win)
L = Σ P(i,j)·(full_loss + ½·half_loss)
q = W / (W + L)
```

| Линия | Пример на счёте 0:0 |
|-------|---------------------|
| **0** | push → вне знаменателя |
| **−0.5** | loss (нет push на .5) |
| **−0.25** | half_loss (push на 0, loss на −0.5) |
| **+0.75** | full win; при 0:1 — half_loss (+0.5 loss, +1.0 push) |

Затем:

```text
λ_h = (S + D) / 2
λ_a = (S − D) / 2
D ← clamp(D, −S+ε, S−ε)
```

**Диагностика clamp D:** при обучении логируется и показывается в UI, сколько матчей упёрлись в границу (trim ≠ 0 или D на `±S±ε`). Если **>2%** выборки — возможен конфликт AH vs OU или ошибка в линиях.

Особенно важно смотреть clamp в контекстах (помечаются в UI и логе):

| Контекст | Критерий |
|----------|----------|
| **Новичок / мало матчей** | у команды ≤3 матчей в выборке |
| **Начало сезона** | матч в первых 25% по дате |
| **Дерби** | `derby_weight = 1`, не нейтраль |
| **Нейтраль** | `is_neutral = true` |

**Пример (Inter – Roma):** тотал 2.5, фора −0.75 → S ≈ 2.72, D ≈ 0.82 → λ_h ≈ 1.77, λ_a ≈ 0.95.

### Шаг 3. Веса матча

**Базовый вес:**

```text
w_base = season_weight × match_weight × neutral_mult

neutral_mult = is_neutral ? neutral_weight : 1.0
```

| Множитель | Откуда | Пример |
|-----------|--------|--------|
| `season_weight` | таблица на «Линии» | прошлый сезон 0.7 |
| `match_weight` | БД / «История» → Вес | низкая мотивация 0.5 |
| `neutral_weight` | БД, если нейтральное поле = да | 0.8 |

**Дерби не входит в вес.** В БД колонка `derby_weight` хранит флаг: **1** = дерби, **0** или пусто = не дерби.  
По умолчанию у всех матчей дерби **выключено**, пока не отметите в блоке **▼ Веса** на «Истории».

`match_weight = 0` — матч не влияет на обучение.  
Метка `low_motivation` в `note` — только для человека; в формулу входит **число** `match_weight`.

**Дополнительно на этапе силы** (рейтинг `r`):

```text
w_line_AH = clamp( 1 / (1 + α_AH · |D|²), 0.15, 1 )
w = w_base × w_line_AH × w_Huber
```

Большой перевес по форе → матч слабее влияет на рейтинг (default α_AH = 0.25).

**На этапе атаки/обороны:**

```text
w_line_T = clamp( 1 / (1 + α_T · (S − S̄)²), 0.3, 1 )
w = w_base × w_line_T × w_Huber
```

Экстремальный тотал → меньший вес (default α_T = 0.5).

`w_Huber` — робастность: выбросы по остаткам ослабляются (итеративный Huber).

### Шаг 4. Рейтинг силы команд

Взвешенная регрессия (robust WLS):

```text
D_m ≈ r_home − r_away + H_league · I_home + δ_derby · I_derby_home
```

- `D_m` — разница из шага 2  
- `r_team` — сила команды (сумма по лиге = 0)  
- `H_league` — домашнее преимущество в обычных матчах  
- `I_home = 0` если `is_neutral`  
- `I_derby_home = 1` если матч дерби и не нейтральное поле  

**δ_derby** оценивается только если в выборке **≥ 3** дерби-матчей (default).  
Shrinkage: `δ_used = w · δ_raw`, `w = n_derby / (n_derby + τ)`, default `τ = 30`.

### Шаг 4b. Нейтральное поле vs нейтр. вес

| Поле | Что делает |
|------|------------|
| **Нейтральное поле** (`is_neutral`) | факт: матч на нейтрали? При «да» — **нет H** (`I_home = 0`), дерби-индикатор тоже 0 |
| **Нейтр. вес** (`neutral_weight`) | насколько доверять этому нетипичному матчу **при обучении** (множитель в `w_base`) |

Это разные вещи: нейтральное поле меняет **формулу**, нейтр. вес — только **вес** строки.  

### Шаг 5. Атака и оборона

```text
log λ_h = μ + A_home − Df_away + H_g · I_home
log λ_a = μ + A_away − Df_home
```

Σ A = 0, Σ Df = 0. Те же веса `w_base × w_line_T × w_Huber`.

### Шаг 6. Калибровка под 1X2

Если есть 1X2 в истории:

```text
D_cal = a + b · D_model
S_cal = c + d · S_model
```

Подгонка по Shin-вероятностям 1X2. Опционально **Dixon–Coles** (γ) — поправка счётов 0:0, 1:0, 0:1, 1:1.

### Шаг 7. Модель ничьи (если включена)

Обучение logit(P_X) от |D| и S на истории.  
В **прогнозе** целевая ничья слегка корректирует диагональ матрицы:

```text
q = clamp(P_X^target / P_X^matrix, q_min, q_max)
```

Defaults: q_min = 0.90, q_max = 1.10 (±10%). Широкий диапазон 0.85–1.15 — только для экспериментов.

## 5. Прогноз матча («Рассчитать линию»)

### Вход

- Лига справочника, хозяева, гости (из **Справочника**).  
- Флаги: **нейтраль** (`H_eff = 0`), **дерби** (другое `H_eff`), **маржа %**.

### Расчёт λ

```text
H_eff = effective_home_advantage(H_league, δ_derby, флаги)
D_pred = r_home − r_away + H_eff
S_pred = из модели атаки/обороны + калибровка

D_final = a + b · D_pred
S_final = c + d · S_pred

λ_h = (S_final + D_final) / 2
λ_a = (S_final − D_final) / 2
```

**H_eff при дерби:**

```text
H_eff = shrink(H_league + δ_used)     # если δ оценена (≥3 дерби в обучении)
H_eff = derbyDefaultFactor × H_league      # мало дерби в обучении (default 0.7; 0.4 — агрессивно)
H_eff = H_league                      # не дерби
H_eff = 0                             # нейтраль
```

Команда без матчей в обучении → рейтинг **новичка** (среднее N слабейших в лиге).

### Матрица и рынки

```text
P(i,j) = Pois(i; λ_h) · Pois(j; λ_a)   [+ DC, + коррекция ничьи]
```

Из одной матрицы:

| Рынок | Как |
|-------|-----|
| 1X2 | Σ по треугольникам |
| Тоталы | Over/Under по сумме i+j |
| Форы | покрытие с линией в **букмекерской** конвенции |
| ИТ | тотал одной команды |
| Топ счетов | максимальные P(i,j) |

**Центральная линия** — где кэфы сторон ≈ равны (бинарный поиск).

**С маржой:** `K = 1 / (p · (1 + margin))`.

## 6. Настройки вкладки «Линия»

| Параметр | Default | Эффект |
|----------|---------|--------|
| α форы | 0.25 | ослабление матчей с большим \|D\| в рейтинге |
| α тотала | 0.5 | ослабление экстремальных S в A/Df |
| prior α | 0.7 | стягивание к прошлому сезону (desktop/расшир.) |
| q_min / q_max | 0.90 / 1.10 | лимит коррекции ничьи (±10%) |
| Модель ничьи | вкл | отдельная P(X), иначе чистый Пуассон |
| Dixon-Coles | вкл | низкие счёты |
| N слабейших (новичок) | 3 | рейтинг незнакомой команды |
| Маржа % | 3 | только в прогнозе, не в обучении |

## 7. Частые вопросы

**Почему AH1 высокий при минусе на фаворите?**  
Рынок оценивает вероятность **покрытия форы**, а не просто победы. −1 @ 2.83 значит «фаворит, но −1 трудно».

**Куда делся `quality_flag` / низкая мотивация?**  
В **`match_weight`** (колонка «Вес» в Истории). `note = low_motivation` — подпись.

**Нужно ли менять знак форы при загрузке?**  
Нет, если это фора **хозяев** как у бука.

**Почему «мало матчей»?**  
Нет полной линии (AH + тотал + 4 кэфа) или пустая выборка сезонов.

**Чем отличается «Нейтральное поле» от «Нейтр. вес»?**  
Нейтральное поле — факт матча: без домашнего преимущества. Нейтр. вес — только ослабление вклада строки при обучении (если нейтраль = да).

**Как отметить дерби?**  
Вкладка **История** → строка матча → **▼ Веса** → **Дерби = да**. В БД пишется `derby_weight = 1`. По умолчанию у всех матчей дерби **нет** (`0`).

**Переобучение после правок в Истории?**  
Да: снова «Загрузить из БД» → «Обучить модель».
