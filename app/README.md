# Калькулятор средней A (десктоп)

Десктоп-приложение на Python + Tkinter, повторяющее исходный интерфейс расчёта средней `A` по линиям 1X2, с добавленным выбором метода усреднения.

## Что считает

Для каждой строки:

```
A = (Коэф гости − 1) / (Коэф дома − 1)
```

Перед усреднением выполняется **фильтр аномальных выбросов по IQR** (метод Тьюки ×1.5), затем «Средняя А» считается по «чистым» значениям выбранным методом.

### Фильтр аномалий (IQR ×1.5)

1. Собрать все `A`, отсортировать по возрастанию.
2. `Q1` = перцентиль 0.25, `Q3` = перцентиль 0.75 (линейная интерполяция).
3. `IQR = Q3 − Q1`.
4. Границы: `lower = Q1 − 1.5·IQR`, `upper = Q3 + 1.5·IQR`.
5. Аномалия: `A < lower` **или** `A > upper`.
6. Аномальные строки помечаются в колонке `A` красным с пометкой `✕` и **исключаются** из расчёта.

Итоговый коэффициент = среднее (по умолчанию **геометрическое**) по неаномальным значениям. Чекбокс «Исключать аномалии (IQR ×1.5)» позволяет отключить фильтр (например, для сравнения). При `n < 4` фильтр не применяется (квартили неустойчивы).

## Интерфейс

- Три колонки: **Коэф дома**, **Коэф гости**, **A** (последняя — только вывод).
- Поля: **Результат**, **A:**, **X :**, **Средняя А**.
- Поле **Метод расчёта** (добавлено):
  - `Среднеарифметическое` — по умолчанию (как в исходной версии);
  - `Геометрическое`;
  - `Линейное усечённое 5%`;
  - `Усечённо-геометрическое 5%`.
- Кнопки: **Считать** и **Считаем А лиги**.

### Поля результата (по неаномальным значениям)

| Поле | Значение |
|------|----------|
| **Результат:** | Итоговый коэффициент A = **геометрическое** среднее валидных |
| **A:** | Среднеарифметическое валидных |
| **X :** | Медиана валидных |
| **Средняя А** | Среднее валидных **выбранным методом** |

Под полями — сводка: число строк / валидных / аномалий, `Q1`, `Q3`, `IQR`, границы и три средних.

### Кнопки

| Кнопка | Действие |
|--------|----------|
| **Считать** | Считает `A`, выбросы и итоги по валидным значениям |
| **Считаем А лиги** | То же; «Результат» выводится с полной точностью (А лиги) |

## Запуск

```bash
python3 app/fair_odds_calc.py
```

Требуется Tkinter:

- **Windows / macOS:** входит в стандартный установщик python.org.
- **Linux (Debian/Ubuntu):** `sudo apt-get install python3-tk`.

Внешних зависимостей нет — только стандартная библиотека.

## Сборка в .exe (Windows)

Готовый `.exe` собирается через PyInstaller (один файл, без консоли).

### Вариант 0: готовый .exe из Releases (для передачи другу)

Самый простой способ поделиться: вкладка **Releases** репозитория → последний релиз → скачать `FairOddsCalc.exe` и запустить двойным кликом. Прямая ссылка вида:

```
https://github.com/<owner>/<repo>/releases/latest/download/FairOddsCalc.exe
```

Релиз с `.exe` публикуется автоматически при пуше тега `vX.Y.Z` (workflow ниже).

При первом запуске Windows может показать SmartScreen («Windows защитила ваш компьютер») — это потому, что файл не подписан сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.

### Вариант 1: артефакт сборки GitHub Actions

В репозитории есть workflow [.github/workflows/build-windows.yml](../.github/workflows/build-windows.yml). При пуше в `app/` он собирает `.exe` на Windows-раннере.

Скачать: вкладка **Actions** → последний запуск **Build Windows EXE** → **Artifacts** → `FairOddsCalc-windows`. Можно запустить вручную кнопкой **Run workflow**.

### Вариант 2: локально на Windows

```bat
pip install pyinstaller
pyinstaller --onefile --windowed --name FairOddsCalc app\fair_odds_calc.py
```

Результат: `dist\FairOddsCalc.exe` — самодостаточный файл, Python на машине пользователя не нужен.

> Примечание: настоящий Windows `.exe` собирается **только на Windows** (или в CI на `windows-latest`). На Linux/macOS PyInstaller создаёт бинарник под текущую ОС, а не `.exe`.

## Формат ввода

- По одному коэффициенту в строке в колонках «Коэф дома» и «Коэф гости».
- Десятичный разделитель — точка или запятая.
- Число строк в двух колонках должно совпадать.

## Методы усреднения

| Метод | Формула |
|-------|---------|
| Среднеарифметическое | `Σ Aᵢ / n` |
| Геометрическое | `exp( mean( ln Aᵢ ) )` |
| Линейное усечённое 5% | отбросить 5% значений с каждого края, затем среднее |
| Усечённо-геометрическое 5% | усечение 5% в лог-пространстве, затем `exp(среднее)` |

При малом `n` усечение 5% не отбрасывает элементов (`int(n·0.05)=0`) и совпадает с полным средним — это корректно.

> Фильтр IQR и усечение 5% — независимые механизмы: сначала IQR убирает аномалии, затем выбранный метод (включая усечённый) применяется к оставшимся значениям.
